## Périmètre

Ce fichier s'applique uniquement au site `horville-labs.fr`.

Il ne s'applique pas à :
- `bhorville-it.fr`
- `onpremsoftware.com`
- `onpremsoftware.fr`

Les règles générales du dépôt racine restent applicables.

### Gestion de configuration

Toute information configurable doit être centralisée dans un fichier de configuration dédié plutôt que durcie dans le code. Cette pratique facilite les maintenances et assure la cohérence entre les différentes pages du site.

---

## Identité

Horville Labs est une vitrine / un laboratoire de projets.

Horville Labs doit rester **anonyme**.

Ne pas afficher ou introduire inutilement :
- nom personnel ;
- prénom ;
- biographie personnelle ;
- CV ;
- identité professionnelle ;
- lien permettant de transformer Horville Labs en extension de `bhorville-it.fr`.

Horville Labs conserve sa propre identité éditoriale.

---

## Relation avec OnPrem Software

Horville Labs peut faire référence à `onpremsoftware.com` :

lorsqu'un projet présenté sur Horville Labs devient ou correspond à un produit / projet OnPrem Software.

La relation autorisée est :

**Horville Labs → OnPrem Software**

Ne pas créer automatiquement de relation inverse :

**OnPrem Software → Horville Labs**

En particulier, ne pas ajouter de lien vers Horville Labs dans :

- la navigation principale d'OnPrem Software ;
- le footer d'OnPrem Software ;
- les pages institutionnelles d'OnPrem Software ;
- les métadonnées ;
- les blocs de liens génériques.

Cette contrainte doit être documentée dans le présent `AGENTS.md`, mais elle ne doit pas provoquer l'ajout d'un lien retour dans le projet OnPrem Software.
